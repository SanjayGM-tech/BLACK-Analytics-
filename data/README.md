# Telemetry Dataset Directory

This directory houses the processed telemetry cache files generated by the high-performance data loader.

## Cache Files Generated:
- `data/processed/match_index.parquet`: Fast indexed metadata covering all 796 matches (start time, duration, participant counts, combat statistics).
- `data/processed/telemetry_clean.parquet`: Cleaned, unified 89,104 telemetry rows with decoded events, normalized timestamps in 2026 UTC, entity classification, and pre-calculated map coordinates.

## Source Dataset Placement:
The raw production data is stored in `player_data/` at the root of the repository:
```
player_data/
├── February_10/
├── February_11/
├── February_12/
├── February_13/
├── February_14/
├── minimaps/
└── README.md
```
If deploying to a fresh environment without pre-built caches, the application will automatically scan `player_data/` and construct the clean parquet caches on the first launch.
